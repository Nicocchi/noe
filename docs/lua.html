Lua API

Everything hangs off the global noe table. Lua never sees an editor pointer — only strings, numbers, and bools.

Lifecycle

  1. Odin registers default commands and keys.
  2. The editor starts, then script_init creates a Lua 5.4 VM.
  3. package.path is prepended with the config dir (?.lua and ?/init.lua).
  4. init.lua is loaded if it exists.
  5. lex\*.lex files in the same config tree are loaded for highlighting.
  6. Untitled buffers pick up newline / split_t from settings.

Ctrl+Shift+R resets settings to defaults, restores the default keymap, drops Lua commands/hooks/status, clears require’s registry cache, and re-runs init.lua. Font size and path rebuild the atlas on the next frame.

noe.set(name, ...)

Write a setting. Colors take one gray 0–255 or three RGB values. Unknown names raise unknown setting.

noe.set("tab_width", 4)
noe.set("bg", 35)
noe.set("selection", 64, 102, 158)
noe.set("use_tabs", true)
noe.set("newline", "lf")  -- or "crlf"

Full list: Settings.

noe.get(name) → value(s)

Read a setting back. Numbers, bools, and strings return one value. Colors return three integers 0–255.

local w = noe.get("tab_width")
local r, g, b = noe.get("bg")

noe.bind(chord, command)

Map a chord to a command name (Odin or Lua). Chord is lowercase, +-separated: ctrl, shift, alt, then a key. A space starts a window sequence: the second token is the key after window_prefix (Ctrl+W).

noe.bind("ctrl+s", "file_save")
noe.bind("ctrl+shift+r", "reload_config")
noe.bind("alt+up", "line_up")
noe.bind("f5", "file_save")
noe.bind("ctrl+-", "dedent")
noe.bind("ctrl+w", "window_prefix")
noe.bind("ctrl+w h", "view_left")
noe.bind("ctrl+w l", "view_right")

Keys: a–z, 0–9, f1–f12, left / right / up / down, enter, backspace, escape / esc, tab, home, end, delete, page_up, page_down, space, insert, backslash, and punctuation - = , . / ; ' [ ] ` (also minus, equal, semicolon, apostrophe, grave, …).

ctrl++ does not parse (split on +). Use ctrl+= or ctrl+equal. Bind letters and digits with a modifier; a bare 1 still inserts 1 via WM_CHAR. Use a space for Ctrl+W sequences (ctrl+w h), not ctrl+w+h.

noe.bind_window(chord, command)

Same as noe.bind("ctrl+w " .. chord, command). The chord is only the second key ("h", "left", "q").

noe.bind_window("h", "view_left")
noe.bind_window("q", "buffer_close")

noe.unbind(chord)

Remove a chord. A space unbinds a window-sequence key. Defaults come back on a full config reload.

noe.unbind("ctrl+n")
noe.unbind("ctrl+w h")

noe.unbind_window(chord)

Remove a second-key window bind.

noe.unbind_window("h")

noe.command(name, fn)

Register a Lua function as a command. fn takes no arguments. Keybinds look up Lua names first, then Odin.

noe.command("hello", function()
    print("hello from lua")
end)
noe.bind("ctrl+'", "hello")

noe.run(name)

Call a command from Lua. Odin first, then Lua. That lets a Lua wrapper keep the original:

noe.command("file_save", function()
    print("saving")
    noe.run("file_save")  -- Odin's save, not this function
end)

Call other Lua functions directly (hello()), not through noe.run, unless they only exist as Odin names.

noe.hook(kind, fn)

kind is "save", "open", or "change". fn receives the buffer path (may be empty for untitled). Multiple hooks per kind stack.

  • save — after a successful write
  • open — after a file is loaded
  • change — when an edit group ends (can fire every keystroke; keep it cheap)
noe.hook("save", function(path)
    print("saved", path)
end)

noe.status(fn) → left, right

Replace the status line. Return two strings. Called every redraw — do not allocate heavily. If the function errors, the built-in line is used.

noe.status(function()
    return "NOE", tostring(noe.get("tab_width"))
end)

require

Standard Lua require. Modules live next to init.lua. Reload clears the real _LOADED cache so theme.lua is read again.

-- %APPDATA%\noe\theme.lua
noe.set("bg", 20)

-- init.lua
require("theme")

Errors

Load/runtime errors print to the terminal as Lua: .... A failed init.lua still leaves the default keymap, including reload. Save the file, then Ctrl+Shift+R.
