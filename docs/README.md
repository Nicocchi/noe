# NOE docs

Static HTML. Open `index.html` in a browser (no server required).

GitHub Pages serves this folder from `main` (`/docs` → https://nicocchi.github.io/noe/). Empty `.nojekyll` skips Jekyll.

```
docs/
  index.html      Overview, build / release zip, AppData layout
  lua.html        Lua API
  settings.html   noe.set / noe.get
  commands.html   Commands and default keys
  examples.html   init.lua snippets
  css/style.css
  js/nav.js
  res/noe.png
  .nojekyll
```
