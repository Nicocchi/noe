Examples

Drop Lua in %APPDATA%\noe\ (init.lua, optional themes\). Highlighters go in %APPDATA%\noe\lex\. Save, then Ctrl+Shift+R. A release zip is only noe.exe + lua54.dll; this folder is created on first run.

Minimal init.lua

noe.set("font_size", 18)
noe.set("tab_width", 4)
noe.set("use_tabs", true)
noe.set("bg", 35)
noe.set("text", 230)

Split theme into theme.lua

theme.lua next to init.lua:

noe.set("bg", 20)
noe.set("text", 230)
noe.set("selection", 64, 102, 158)
noe.set("caret", 230)
noe.set("gutter", 128)
noe.set("gutter_current", 204)
noe.set("divider", 115, 115, 122)
noe.set("status_bg", 56)
noe.set("status_text", 191)
noe.set("overlay_bg", 41, 41, 46)
noe.set("overlay_label", 178, 204, 242)

init.lua:

require("theme")

noe.set("text_pad_x", 8)
noe.set("text_pad_y", 8)
noe.set("pad_y", 0)

Custom command + bind

noe.command("hello", function()
    print("hello from lua")
end)
noe.bind("ctrl+'", "hello")

print shows in a console. ./build.sh links a windowed exe, so run with odin run src if you want that output.

Wrap save

noe.command("file_save", function()
    print("saving")
    noe.run("file_save")
end)

noe.run calls the Odin command, so this does not recurse. Ctrl+S still named file_save hits the Lua wrapper first.

Hooks

noe.hook("save", function(path)
    print("saved", path)
end)

noe.hook("open", function(path)
    print("opened", path)
end)

-- noisier: every edit group
-- noe.hook("change", function(path) end)

Status line

noe.status(function()
    local tab = noe.get("tab_width")
    return "NOE", "tab " .. tostring(tab)
end)

Font + fallback

noe.set("font_size", 22)
noe.set("font_path", "C:/Windows/Fonts/CascadiaCode.ttf")
-- noe.set("font_fallback", "C:/Windows/Fonts/msyh.ttc")

Takes effect on reload. A missing primary path keeps the last good font.

Spaces, CRLF, no pairing

noe.set("use_tabs", false)
noe.set("tab_width", 2)
noe.set("newline", "crlf")
noe.set("smart_brackets", false)

Rebind open, extra panes

Default Ctrl+N is file_new. This gives that chord to open instead:

noe.unbind("ctrl+n")
noe.bind("ctrl+n", "file_open")
noe.bind("ctrl+w", "window_prefix")
noe.bind("ctrl+w h", "view_left")
noe.bind("ctrl+w l", "view_right")
noe.bind("ctrl+w j", "view_down")
noe.bind("ctrl+w k", "view_up")
noe.bind("f5", "file_save")

Full-ish skeleton

require("theme")

noe.set("tab_width", 4)
noe.set("blink_ms", 530)
noe.set("pad_x", 12)
noe.set("pad_y", 0)
noe.set("text_pad_x", 8)
noe.set("text_pad_y", 8)
noe.set("split_gap", 6)
noe.set("split_t", 0.5)
noe.set("use_tabs", true)
noe.set("newline", "lf")
noe.set("smart_brackets", true)
noe.set("font_size", 18)
noe.set("show_gutter", true)
noe.set("show_status", true)
noe.set("show_brace_header", true)
noe.set("show_brace_guides", true)
noe.set("brace_guide", 102, 102, 112)
noe.set("find_case_sensitive", true)
noe.set("scroll_margin", 1)

noe.status(function()
    return "NOE", tostring(noe.get("tab_width"))
end)

noe.hook("save", function(path)
    print("saved", path)
end)

noe.bind("ctrl+shift+r", "reload_config")

reload_config is already on Ctrl+Shift+R in the default keymap; the bind is optional.
