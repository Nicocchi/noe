All built-in names

CommandWhat it does
cursor_left … cursor_downMove primary caret, clear extras
select_left … select_downExtend selection
cursor_word_left / rightWord motion (Ctrl+Left / Right)
select_word_left / rightWord select
cursor_home / endLine start / end
select_home / endSelect to line start / end
cursor_doc_home / endBuffer start / end
select_doc_home / endSelect to buffer start / end
cursor_page_up / downPage jump
select_page_up / downSelect by page
delete_backward / delete_forwardBackspace / Delete (pair-aware if smart brackets)
insert_newlineEnter + smart indent
indent / dedentTab / Shift+Tab using use_tabs
line_up / line_downSwap the line (or selected lines) with the neighbor. Indent matches that line; one extra level when moving down through {[( or up through }])
select_allWhole buffer
add_next_matchMulti-cursor: next same range
carets_clearDrop extra carets
undo / redoJournal; restores carets
edit_copy / cut / pasteClipboard UTF-16
file_open / file_save / file_save_asWin32 dialogs
file_newNew-file overlay: browse the project, name a file, Ctrl+R rename, Ctrl+D delete
file_finderProject file picker with fuzzy filter and preview; already-open paths use the function color
window_prefixStart a Ctrl+W sequence; next key is a pane command
buffer_closeClose the active buffer. Unsaved files prompt Save / Discard / Cancel. The last buffer becomes untitled. Bound as Ctrl+W Q / C
findFind overlay
buffer_switcherOpen-buffer overlay; names are paths from the project root. A number jumps to that line
view_nextSecond pane on the same buffer
view_left / view_right / view_up / view_downFocus pane. Up/down are no-ops until vertical splits exist
toggle_commentToggle the lexer line-comment mark on the current line or selection
reload_configReload *.lex files and re-highlight open buffers
Mouse: click to focus a pane, drag to select (edge pan), drag the split (resize cursor). Overlay steals keys until Escape or click-outside.

No vertical split commands yet.
